# MarketLink

Integrated ASP.NET Core MVC application targeting .NET 10.

- Admin: `/Admin`
- Customer: `/Customer`
- Shared database/context: `MarketLinkDbContext`
- Admin authentication: `AdminAuth`
- Customer authentication: `CustomerAuth`

See **README_INTEGRATION.md** for the complete integration notes, database migration details, configured development URLs, credentials, and validation status.
